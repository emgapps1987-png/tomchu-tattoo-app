# הצהרות בריאות ישר למייל של תום – הקמה חד־פעמית (כ־5 דקות)

אחרי ההקמה, כל לקוח שממלא הצהרת בריאות באפליקציה:
1. **שולח מייל ל־TomchuTattoo@gmail.com** עם כל הפרטים, קובץ PDF חתום ותמונת החתימה. אם סומנה תשובת "כן" לאחת השאלות, כתוב ⚠ בכותרת המייל.
2. **ה־PDF נשמר בדרייב** בתיקייה "Tomchu – הצהרות בריאות".
3. **נוספת שורה לגיליון** "Tomchu – הצהרות בריאות", עם כל ההצהרות במקום אחד.

הכל נשאר בחשבון הגוגל של תום, בלי שירות חיצוני ובלי עלות.

## ההקמה – מהמחשב, מחוברים ל־TomchuTattoo@gmail.com
1. נכנסים ל־**https://script.new** (נפתח פרויקט חדש ב־Google Apps Script).
2. נותנים לפרויקט שם למעלה: **Tomchu – הצהרות בריאות**.
3. מוחקים את כל מה שכתוב בעורך, ומדביקים את כל התוכן של הקובץ `google-apps-script.gs`. שומרים (Ctrl+S).
4. **בדיקה:** בשורה העליונה בוחרים את הפונקציה **testEmail** ולוחצים **הפעלה (Run)**.
   - גוגל תבקש הרשאות: **Review permissions** ← בוחרים את החשבון ← **Advanced (מתקדם)** ← **Go to Tomchu – הצהרות בריאות** ← **Allow (אישור)**.
   - האזהרה מופיעה כי זה סקריפט פרטי שלכם ולא אפליקציה מאומתת. ההרשאות הן רק לשליחת מייל, ליצירת קבצים בדרייב ולגיליון, בחשבון של תום בלבד.
   - תוך דקה אמור להגיע מייל בדיקה עם PDF.
5. **פרסום:** **Deploy (פריסה) ← New deployment (פריסה חדשה)** ← בגלגל השיניים בוחרים **Web app (אפליקציית אינטרנט)**:
   - Execute as (הפעלה בתור): **Me (אני)**
   - Who has access (למי יש גישה): **Anyone (כל אחד)**
   - ← **Deploy** ← מעתיקים את ה־**Web app URL**. הכתובת מתחילה ב־`https://script.google.com/macros/s/...` ומסתיימת ב־`/exec`.
6. **שולחים את הכתובת ל־Claude**, והוא יחבר אותה לאפליקציה.

> "Anyone" אומר רק שהאפליקציה יכולה לשלוח הצהרות לסקריפט. אף אחד לא יכול לקרוא דרכו את המיילים, את הדרייב או את הגיליון.
