# Tomchu Tattoo – אפליקציית לקוחות

אפליקציית ווב (PWA) לסטודיו של תום: אפשר להכיר את תום, לראות עבודות, לקרוא מאמרים ואת מדריך ההחלמה, לשלוח פנייה מסודרת ולמלא הצהרת בריאות עם חתימה באצבע.
אפשר להתקין אותה על המסך הראשי של הטלפון, והיא עובדת גם בלי אינטרנט.

## להתקין על הטלפון
- **אייפון (Safari):** כפתור השיתוף ← "הוספה למסך הבית".
- **אנדרואיד (Chrome):** תפריט שלוש הנקודות ← "התקנת אפליקציה".

## מה יש באפליקציה
| מסך | מה יש בו |
|---|---|
| בית | לוגו, פנייה מהירה, מדריך החלמה, עבודות, מאמרים, ניווט לסטודיו |
| תום | היכרות, איך אני עובדת, הסטודיו, שאלות נפוצות, רשתות חברתיות |
| פנייה לתום | טופס מסודר שנשלח לוואטסאפ של תום (כולל תמונות השראה בטלפון) |
| בריאות | הצהרת בריאות ב־3 שלבים, בדיקת ת״ז, זיהוי קטינים, חתימה באצבע, שמירה כ־PDF |
| עבודות | גלריה עם סינון לפי סגנון ותצוגה מוגדלת |
| מדריך החלמה / מאמרים / הצהרת נגישות | נפתחים מתוך האפליקציה |

## לשנות טקסטים, שאלות ותמונות
כל התוכן נמצא בקובץ אחד: **`js/content.js`**.
- תמונות עבודות: מוסיפים קובץ לתיקייה `assets/img/works/` ושורה לרשימה `WORKS`.
- שאלות הבריאות: הרשימה `QUESTIONS`.
- מאמרים: הרשימה `ARTICLES`.

אחרי שינוי – כדאי להעלות את `VERSION` בקובץ `sw.js` (למשל ל־`tomchu-v2`) כדי שהטלפונים יקבלו את העדכון.

## לפני עלייה לאוויר – לבדיקת תום
- [ ] לעבור על הטקסטים במסך "תום" ובמאמרים שנכתבו מחדש (10 דברים, סגנונות, מכונות).
- [ ] לעבור על מדריך ההחלמה – שההוראות תואמות בדיוק למה שתום ממליצה.
- [ ] להחליף את שאלות הבריאות בשאלות המדויקות מהטופס בגוגל פורמס.
- [ ] למלא את פרטי נגישות הסטודיו (בהצהרת הנגישות).
- [ ] להחליט אם לחבר שמירה לגיליון Google: `docs/google-apps-script.md`.

## פרטיות
האפליקציה לא שומרת שום מידע אישי בשרת או בדפדפן. במצב הנוכחי הפרטים עוברים ישירות לוואטסאפ של תום, וההצהרה החתומה נשמרת כ־PDF אצל הלקוח.

## טכני
אתר סטטי ללא שלב בנייה (HTML, CSS ו־JavaScript), מתפרסם ב־GitHub Pages מהענף `main`.
להרצה מקומית: `python3 -m http.server` ואז לפתוח `http://localhost:8000`.
